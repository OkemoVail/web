# Soft / Satin Button Variant Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a reusable, accent-tinted `.skuo-soft` button modifier (YouTube-style soft top highlight + smooth satin gradient) and demo it on `design.html`.

**Architecture:** `.skuo-soft` is a surface-treatment modifier added to the existing skuo button family in the single shared stylesheet `src/design-tokens.css`. It reuses the `--skuo-surface` / `--chrome-*` recipe and overrides only the `::before` sheen, the fill gradient, and the lift shadow, so it inherits accent tint and dark-mode behavior automatically. Purely additive — no existing rule changes.

**Tech Stack:** Plain CSS (CSS custom properties, `color-mix`), static HTML. No build step required for the CSS itself (`design-tokens.css` is linked directly, not generated by Tailwind).

## Global Constraints

- Accent-tinted only — no literal dark charcoal. Track `--skuo-surface`. (from spec)
- Purely additive: do NOT modify existing `.skuo` / `.skuomorphic-btn` / `.skuomorphic-button` rules. (from spec)
- No `!important`. Follow existing recipe-variable style. (from CLAUDE.md)
- Place new rules in the skuo section: after `.skuo-neutral` (line ~237) and before `.skuo-icon` (line ~239); dark-mode tweak in the `.dark` block after `.dark .skuo-neutral` (line ~277). (from spec)
- No test suite — verification is visual in a browser, light + dark. (from CLAUDE.md)

### Task 1: Add the `.skuo-soft` modifier to the shared stylesheet

**Files:**
- Modify: `src/design-tokens.css` (insert after `.skuo-neutral` block, before `.skuo-icon`; and in the `.dark` block after `.dark .skuo-neutral`)

**Interfaces:**
- Consumes: existing custom properties `--skuo-surface`, `--skuo-accent`, `--skuo-glow`, `--chrome-shadow-active` (already defined in `:root` and `.dark`).
- Produces: CSS class `.skuo-soft`, used as `class="skuo skuo-soft ..."` by Task 2 and any future page.

- [ ] **Step 1: Insert the `.skuo-soft` rules**

In `src/design-tokens.css`, immediately after the `.skuo-neutral { ... }` block (the one ending `color: var(--text-primary); }`) and before the `/* Compact icon buttons ... */` comment, insert:

```css
/* Soft / satin surface — thin top highlight + smooth even gradient.
   Composes over any --skuo-surface (neutral, accent, dark). Matte, not glossy. */
.skuo-soft {
  background-image: linear-gradient(
    180deg,
    color-mix(in srgb, var(--skuo-surface, #eceae2), white 12%),
    var(--skuo-surface, #eceae2) 55%,
    color-mix(in srgb, var(--skuo-surface, #eceae2), black 7%)
  );
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.45),
    0 1px 2px rgba(0, 0, 0, 0.12),
    0 3px 14px -8px var(--skuo-glow);
}

.skuo-soft::before {
  inset: 1px 1px auto 1px;
  height: 38%;
  background: linear-gradient(
    180deg,
    rgba(255, 255, 255, 0.32),
    rgba(255, 255, 255, 0)
  );
}

.skuo-soft:hover {
  background-image: linear-gradient(
    180deg,
    color-mix(in srgb, var(--skuo-surface, #eceae2), white 18%),
    color-mix(in srgb, var(--skuo-surface, #eceae2), white 2%) 55%,
    color-mix(in srgb, var(--skuo-surface, #eceae2), black 4%)
  );
  box-shadow:
    inset 0 1px 0 rgba(255, 255, 255, 0.5),
    0 2px 4px rgba(0, 0, 0, 0.13),
    0 5px 18px -8px var(--skuo-glow);
}

.skuo-soft:active {
  box-shadow: var(--chrome-shadow-active);
}
```
